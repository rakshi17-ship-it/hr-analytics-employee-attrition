# HR Analytics – Employee Attrition Analysis

## Project Overview
This project focuses on analysing employee attrition to understand workforce trends and identify factors associated with employees leaving an organisation.

Using SQL and Power BI, I cleaned, analysed and visualised HR data to generate meaningful business insights that can support HR decision-making.

## Project Objectives
- Analyse overall employee attrition.
- Identify departments and job roles with higher attrition.
- Understand attrition patterns across different age groups.
- Analyse the relationship between overtime and attrition.
- Explore the association between job satisfaction and employee attrition.
- Examine employee tenure and business travel patterns.

## Tools & Technologies
- PostgreSQL – Data cleaning and SQL analysis
- Microsoft Power BI – Data visualisation and dashboard development
- Microsoft Excel – Data inspection and preparation

## Dataset Information
- Total records: 1,470 employees
- Total columns: 35
- Employees who left: 237
- Employees who stayed: 1,233
- Overall attrition rate: 16.12%

## Project Workflow

1. Data Inspection
2. Data Cleaning using SQL
3. Data Validation
4. Exploratory Data Analysis
5. Business Analysis using SQL queries
6. Dashboard Development using Power BI
7. Business Insights and Recommendations

## Key Business Insights

- Overall employee attrition rate is 16.12%.
- Sales department has the highest department-level attrition rate at 20.63%.
- Sales Representatives have the highest job-role attrition rate at 39.76%.
- Employees working overtime have a higher attrition rate (30.53%) compared with those not working overtime (10.44%).
- Employees aged 18–24 have the highest age-group attrition rate at 39.18%.
- Employees who travel frequently have a higher attrition rate than those who rarely travel.
